研究目标 / 本课题旨在针对复杂工程优化问题中存在的计算昂贵、多模态，黑箱及梯度缺失等挑战，基于课题组先期的理论成果，提出一种基于聚类自适应局部搜索与混合交叉池的混合进化算法。 / 目标是建立一套完整的算法框架，实现从单目标到多目标、从无约束到有约束的扩展，并通过马尔可夫链或图式定理从理论上证明其优越性。最终，结合代理模型技术，通过CEC基准测试集和SolidWorks工业仿真案例的双重验证，验证算法在收敛精度和计算效率上优于标准GA及主流商业软件算法。 / 研究内容 / 算法核心机制深化与算子设计 / 1.1算法整体架构 /  /  /  /  /  /  /  /  /  /  /  /  /  /  /  / 1.2多聚类方法支持 / 算法支持三种聚类方法，适应不同的问题特性： / K-means：经典的划分式聚类，需要预设簇数量 niche_num。适用于已知最优解数量的多模态优化问题。 / MeanShift：基于密度的聚类，自动确定簇数量。算法会根据数据分布估算带宽（bandwidth），无需人工指定簇数。这对于事先不知道有多少个局部最优的问题非常有用。 / DBSCAN：同样基于密度，能发现任意形状的簇。算法会自动估算 eps（邻域半径）和 min_samples（最小样本数），通过 k-距离图方法选择合适的参数 /  / 聚类学习并非每代都执行，而是采用条件触发策略： / 周期性触发：每 5 代执行一次，避免过于频繁的局部搜索消耗过多函数评估次数 / 停滞触发：当连续 3 代没有改进时触发，帮助算法跳出局部最优 / 这种设计的原因是：局部搜索虽然能加速收敛，但会消耗大量函数评估次数（FEs）。通过条件触发，可以在探索效率和收敛速度之间取得平衡。 / 1.3 混合交叉机制 / HA算法采用隐性选择（Implicit Selection）策略，将选择压力内嵌于交叉操作中，而非单独的选择步骤算法组合使用三种交叉策略，各有侧重： / 策略一：适应度加权 SBX 交叉（60%） / 模拟二进制交叉（SBX）是连续优化中最常用的交叉算子。算法在此基础上加入适应度加权： / 选择两个父代时，适应度好的个体更容易被选中 / 交叉产生两个子代时，偏向保留适应度更好父代方向的子代 / 策略二：适应度加权多父代交叉（25%） / 选择 3-5 个父代，按其适应度权重加权组合产生子代。这种策略能够融合多个优秀个体的特征，并通过适度扰动保持多样性。 / 策略三：DE/current-to-best（15%） / 差分进化策略，从当前个体向全局最优个体方向进化，同时加入随机扰动。这为算法提供了明确的进化方向，加速向最优区域收敛 / 。三种策略的比例设置（60%、25%、15%）是经验值，确保算法既有稳定的收敛能力（SBX），又有多样性维护（多父代交叉），还有方向性引导（DE）。 /  / 1.4变异操作策略 / 1.4.1多项式变异 / 算法采用多项式变异（Polynomial Mutation），这是 NSGA-II 等经典算法广泛使用的变异算子。其特点是： / 变异幅度由分布指数 η_m 控制：η_m 越大，变异越集中在原值附近 / 自动感知边界：靠近边界时变异幅度自动减小，避免产生越界解 / 每个维度独立变异，变异概率为 1/dim / 1.4.2自适应分布指数 / 分布指数 η_m 采用自适应策略： / 进化早期（前 50 代）：η_m 较小（约 20），产生较大变异，增强全局探索 / 进化后期：η_m 逐渐增大（最高 100），变异趋于保守，精细化局部搜索 / 停滞时：降低 η_m，增大变异幅度，帮助逃离局部最优 / 这种自适应机制使算法在不同进化阶段自动调整探索与利用的平衡。 / 1.5多样性维护策略 / 算法在每代结束时检测种群多样性。当不重复个体数量降至很低（≤5%种群规模）时，不是简单终止算法，而是： / 注入新鲜血液：用 30% 随机个体替换种群中最差的个体 / 重置步长：将步长设为 0.5，允许在大范围内重新搜索 / 这种策略避免了过早收敛导致的搜索停滞，使算法在后期仍保持探索能力。 /  / 黑箱环境下的梯度获取与局部搜索策略 | 研究目标 /
