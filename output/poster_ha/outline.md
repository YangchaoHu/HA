## 2. 研究背景与工程动机

核心表达：
- 复杂工程优化问题常具有计算昂贵、多模态、黑箱、梯度缺失等特点。
- 工业仿真如 SolidWorks / ANSYS 的单次评估成本高，传统全员局部搜索难以承受。
- 目标是在有限函数评估预算内，提高收敛精度、搜索稳定性和工程可用性。

可视化：
- 顶部或右上角加入工业 CAD / SolidWorks 风格零件、仿真云图、参数化设计空间的背景视觉。
- 使用标签强调：Expensive Simulation、Black-box、Multimodal、No Gradient。

## 3. 核心方法：聚类自适应局部搜索

这是海报的主模块，需要视觉上最突出。

关键点：
- 在决策空间中进行聚类小生境划分，而不是只在目标空间被动筛选。
- 支持 K-means、MeanShift、DBSCAN，分别适配固定簇数、密度结构和任意形状局部盆地。
- 条件触发策略：每 5 代周期触发，或连续 3 代停滞时触发。
- 每个簇选择代表个体执行局部搜索，把有限函数评估预算集中到有潜力区域。
- 历史评估数据可构建 RBF / GP 局部代理模型，为黑箱优化提供“伪梯度”。

图示结构：
种群 -> 决策空间聚类 -> 簇代表 -> 局部代理/局部搜索 -> 改良个体回写 -> 遗传进化

强调句：
“HA 聚类决定谁值得深挖，而不仅是决定谁被保留。”

## 4. 混合交叉池与自适应进化机制

关键点：
- SBX 交叉 60%：稳定继承优秀父代方向。
- 适应度加权多父代交叉 25%：融合多个优秀个体特征，增强复杂曲面搜索能力。
- DE/current-to-best 15%：引入面向当前最优的方向性开发。
- 自适应多项式变异：早期增强探索，后期精细开发，停滞时增大扰动。
- 多样性维护：当重复个体过多时注入 30% 随机个体并重置步长。

图示结构：
三段比例条或环形图：60 / 25 / 15，与变异/多样性模块并列。

## 5. 工业仿真与 SolidWorks 联系

必须体现“从实际出发”的工程闭环。

关键点：
- 以 SolidWorks / ANSYS 参数化模型为真实物理评估端。
- Python HA 生成候选参数，消息队列或接口分发给仿真端。
- 仿真端返回体积、位移、强度等响应，作为目标函数和约束。
- 使用代理模型与增量式采样降低真实仿真次数：LHS 初始样本 -> 代理训练 -> HA 候选搜索 -> 真实回评 -> 数据集更新。
